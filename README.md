# Game
It's a game made with Java. Or better said, a game engine made using Java.
Playable with both controller and keyboard. In menus, use WASD or the arrow keys to move, ENTER or SPACE to confirm and ESCAPE to go back.
Only uses JamePad and Java Swing as dependencies, otherwise it's 100% pure default JDK.
Controller input uses Jamepad (Apache License 2.0), which bundles SDL2 (zlib license), with controller mappings from SDL_GameControllerDB (zlib license).
